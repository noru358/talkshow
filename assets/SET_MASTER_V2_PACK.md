Generate the EMPTY SET first. Do not ask one generation to invent the location and composite all three characters at the same time.

Workflow:
1. Generate one empty 16:9 set image from the exact set prompt below.
2. QC and lock it.
3. Use that exact set image as strict spatial/reference authority.
4. Attach the three character packs: CHAR_B, CHAR_06, RIGHT_MASTER_V2.
5. Generate one canonical three-person cast still for that set.
6. Use that locked still as fixed I2V first frame for clips filmed in that set.

- simple, physically readable furniture geometry
- richer than V1 but not cluttered
- no readable text / logos / watermark

Visual language:
- same low-fi 2D webcomic world as the character sheets
- thick slightly imperfect black outlines
- flat muted colors
- minimal shading
- modest detail
- slightly cheap-cute / hand-drawn irregularity
- NOT polished anime/webtoon
- NOT realism / semi-realism
- NOT cinematic lighting

```text

Use small everyday cues rather than giant symbols or text.
No national flags, no tourist décor, no readable Korean signs.

STYLE:
Match a simple low-fi 2D webcomic world: thick slightly imperfect black outlines, flat muted colors, minimal shading, modest detail, slightly clumsy hand-drawn charm.

Do not make the room polished, cinematic, photorealistic, glossy, or like a lifestyle magazine.

No people.
No text.
No logo.
No watermark.
One single scene only.
```
